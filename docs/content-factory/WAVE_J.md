# Wave J — depth, difficulty and structural diversity

Wave J audits the 189 question-bearing skills already present in Waves A–H. It does not expand curriculum domains and does not claim pedagogical superiority.

## Evidence boundary

- The minimum pool of six comes from the immutable Wave I attempt limit, not a grade-wide pedagogical threshold.
- A retry prefers a different structural fingerprint. If no unseen verified item exists, selection falls back to another verified band and then fails closed.
- Difficulty evidence maps repository `EXTENSION` to the Wave J `ADVANCED` reporting label. Every new label is `CONTRACT_DERIVED` from reasoning steps, coordinated skills, representation changes and constraints.
- Promotion requires two structurally distinct correct results plus mastery evidence. One correct answer never promotes; one calculation slip never triggers deep remediation.

## Production decision

Grades 1–3 and 8–9 are `DEPTH_SUFFICIENT` under the current candidate policy and receive no filler questions. Grade 1 remains metadata-only: the `13 / 312 / 312 / 24` boundary, SQL, source digest, runtime, original shadow tuple and quarantine/UNKNOWN rows are unchanged.

The audit proves 14 structural gaps in Grades 4–7 and adds the minimum 30 source-backed questions:

- Grade 4: fraction ordering, 1 question, page 36.
- Grade 5: fraction ordering, missing fraction addition/subtraction, and applied decimal subtraction/multiplication/division, 6 questions, pages 41–42.
- Grade 6: multiples, missing integer operations, arithmetic properties/brackets, three-number GCD/LCM, irreducibility and fraction add/subtract applications, 11 questions, pages 47–48.
- Grade 7: two new reasoning structures for each of six ratio/proportion outcomes, 12 questions, page 57.

All Wave J and combined A–J candidates remain `DRAFT/HIDDEN`, with publication, pilot, runtime and retention flags false and no default entitlement.

Wave F's historical DNS-attempt incident remains recorded verbatim. Wave J uses only verified local executables in offline mode and records zero new network attempts.
