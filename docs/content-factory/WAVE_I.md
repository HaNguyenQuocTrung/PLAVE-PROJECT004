# Grades 1–9 Wave I: prerequisite, diagnosis and remediation

Wave I audits only skills that already have candidate questions in immutable Waves A–H. It adds deterministic policy candidates and combined A–I bindings without adding filler questions. All candidates remain `DRAFT/HIDDEN`; publication, runtime, pilot and retention flags remain false and no entitlement is created.

## Evidence boundary

Existing prerequisite edges are mechanically classified as `SOURCE_EVIDENCED`, `CONTRACT_DERIVED`, or `HYPOTHESIS_REQUIRES_EVIDENCE`. `CURRICULUM_AUTHORITATIVE` would map to source-evidenced, repository runtime order maps to contract-derived, and every hypothesis stays a hypothesis. The A–H candidate graph contains no authoritative internal candidate-skill edge, so Wave I truthfully reports zero source-evidenced edges rather than inventing one.

Entry skills without an evidenced predecessor use a current-skill retry variant. Terminal skills use retention and mixed practice. These are software actions, not new curriculum prerequisites. Cross-grade targets are suggestions only; neither `schoolGrade` nor entitlement is mutated.

## Diagnostic boundary

The typed taxonomy covers concept-pattern, operation-selection, calculation, place-value, sign, fraction-equivalence, unit-conversion, algebraic-transformation, geometry-constraint, data-interpretation, probability sample-space, multi-step sequencing and insufficient-evidence outcomes. Classification consumes server-side post-submit answer/derivation evidence. A single calculation error retries the current skill; repeated structured evidence is required before prerequisite remediation. Missing evidence returns `INSUFFICIENT_EVIDENCE_UNKNOWN` and fails closed.

No psychological diagnosis or expert pedagogical validation is claimed. Explanations remain unavailable before submission, and retention failure preserves mastery and history.

## Bridge decision

No bridge questions are required. Every audited candidate skill already has at least one A–H question pool, including Grade 1's immutable evidence-backed legacy rows. Grade 1 SQL, content, IDs, fixed runtime, source digest, shadow tuple and visual quarantine remain unchanged.

Wave F's historical registry DNS-attempt incident remains recorded. Wave G/H offline guards are inherited and Wave I adds a zero-network-attempt boundary.
